# 🤠 로프 카우보이 — 납치 & 구출 2D 팀전

올가미(로프)를 돌려 던지는 2D 탑다운 팀 대전 게임입니다. **빌드/설치 불필요** —
`game/index.html` 을 브라우저로 열면 바로 플레이됩니다.

```
game/
  index.html   화면/UI (시작·결과·HUD·모바일 조작)
  style.css     서부 테마 스타일
  game.js       게임 엔진 (입력·물리·AI·렌더·루프, 순수 Canvas)
```

## 핵심 규칙

- **3 대 3 팀전** — 레드(당신 + AI 2) vs 블루(AI 3).
- 🎯 **납치**: 올가미 끝이 활동 중인 **적**에 맞으면, 그 적을 **우리 감옥**으로 끌어옵니다.
- 🛟 **구출**: 적 감옥에 끌려가거나 갇힌 **우리 팀**을 올가미로 맞히면 즉시 풀려납니다(끌려가는 도중에도 가능).
- 🧗 **넘기(2.5D)**: 벽의 **노란 고리**에 올가미를 걸면 로프에 끌려 포물선으로 **벽을 넘어갑니다**(점프 중엔 충돌 무시 + 그림자로 높이 표현).
- 📦 **상자 끌기**: 상자에 올가미를 걸면 내 쪽으로 끌어와 엄폐물로 쓰거나 길을 막을 수 있습니다.
- 🏆 **승리**: 적 3명을 **동시에** 가두면 즉시 승리. 2분 종료 시 더 많이 가둔 팀 승리.

## 조작

| 동작 | 키 |
|------|-----|
| 이동 | `W A S D` 또는 방향키 |
| 조준 | 마우스 |
| 올가미 던지기 | 왼클릭 / `Space` (**길게 누르면 충전 → 더 멀리·빠르게**) |
| 대시(구르기) | `Shift` |

모바일/태블릿은 좌측 **가상 조이스틱**으로 이동·조준, 우측 **올가미 버튼**으로 발사합니다.

## 난이도

시작 화면에서 **쉬움 / 보통 / 어려움** 선택 — AI의 이동 속도·사거리·조준 정확도·반응 속도가 달라집니다.

## 실행

별도 서버가 필요 없습니다.

```bash
# 방법 1) 그냥 파일 열기
#   game/index.html 더블클릭 (또는 브라우저로 드래그)

# 방법 2) 로컬 서버로 (권장: 일부 브라우저 보안정책 회피)
cd game
python3 -m http.server 8080
#  → http://localhost:8080 접속
```

## 향후 확장 아이디어

- 같은 저장소의 **P2P 메시 네트워크(`peer.js`)** 위에 상태 동기화를 얹어 실시간 온라인 팀전으로 확장.
- 깃발 뺏기·체력·아이템(부메랑 올가미, 이중 갈고리) 등 모드 추가.
- 맵 에디터 / 다양한 아레나.
