# P2P 사내 메신저 (중앙서버 없음)

같은 네트워크(같은 와이파이/사내망)에 있는 **약 40명**이 쓰는 **완전 P2P** 메신저입니다.
**중앙서버가 없습니다.** 각자 자기 PC에서 이 프로그램을 실행하면, 같은 망의 동료를
**자동으로 발견해 서로 직접 연결**하고 메시지를 주고받습니다.

데이터 구조는 **Zulip 방식**입니다 — 모든 메시지는 `채널(채널) > 주제(topic)`에 속하므로
주제별 스레드 중심으로 깔끔하게 운영됩니다.

```
   [내 PC]  ⇄  [동료 A]  ⇄  [동료 B]
      ⇅            ⇅           ⇅
   브라우저      브라우저     브라우저   ← 각자 자기 PC의 http://localhost:34567
```

## 동작 방식

- **자동 발견**: UDP 멀티캐스트(`239.255.41.42:50505`)로 같은 망의 노드를 서로 찾음
- **직접 연결**: 발견한 노드끼리 TCP 메시(mesh)로 직접 연결 (중앙 경유 없음)
- **메시지 전파**: gossip 방식으로 모든 노드에 퍼짐
- **늦은 합류 동기화**: 나중에 켠 PC는 연결 즉시 누락된 대화를 받아옴(최종 일관성)
- **로컬 UI**: 브라우저는 오직 "자기 PC 노드"의 `localhost`에만 접속

## 주요 기능

- 채널(여러 개) + 채널 직접 만들기
- **채널 안의 주제(topic) 스레드** — 주제 목록 보기 / 새 주제 시작 / 주제별 대화
- **1:1 다이렉트 메시지(DM)** — 접속자 목록에서 상대를 클릭하면 비공개 1:1 대화. 두 사람에게만 전달·저장(제3자 제외)되고, 상대가 오프라인이면 다시 접속할 때 받습니다.
- **AI 요약** — 주제/DM 화면의 📝 버튼으로 대화 전체 요약, 안 읽은 메시지가 있으면 "읽은 부분 요약"으로 빠르게 캐치업. (이 배포본은 **로컬 Ollama `gemma3:4b` 가 기본 내장** — 요약 대화가 외부로 안 나감. 각 PC에 Ollama 설치 필요, 미설치 시 요약만 안내문이고 나머지 기능은 정상)
- **메시지 리액션** — 메시지에 마우스를 올려 😊 버튼으로 👍❤️😂🎉😮😢 반응(누구나, 다시 누르면 취소)
- **메시지 수정** — 내 메시지의 ✏ 버튼으로 본문 수정(모두에게 반영, "(편집됨)" 표시)
- **@멘션** — 입력창에서 `@`를 치면 접속자 **자동완성** 목록이 뜨고, 지목된 사람에게 🔔 알림 + 사이드바 강조 배지 + 본문 하이라이트
- **투표** — 작성창 📊 버튼으로 질문·선택지(복수 선택 가능) 투표를 만들고 막대그래프로 실시간 집계. DM에서도 가능(당사자만)
- **수합(설문/제출)** — 작성창 📥 로 질문(자유서술/객관식)·마감을 만들어 응답을 모음. **누가 제출/미제출인지** 한눈에 보이고 결과를 `.txt` 로 내보냄. DM에서도 가능(당사자만)
- **일정 조율(when2meet)** — 작성창 📅 로 후보 시간대를 올리면 각자 가능한 시간을 체크 → **공통 가능 시간(최적)을 자동 하이라이트** + 미응답자 표시. DM에서도 가능
- **작업/담당 추적** — 작성창 📋 로 할 일·담당자·기한을 만들면 **담당자별 진행상태(할 일/진행 중/완료)** 와 완료 집계를 추적. DM에서도 가능
- **확인(ACK)** — 메시지에 마우스를 올려 ✓ 를 누르면 "확인했음" 표시. **누가 확인/미확인인지** 추적(공지·지시 도달 확인용). DM에서도 가능
- **답글/인용** — 메시지에 마우스를 올려 ↩ 로 특정 메시지에 답글. 인용 미리보기를 보여주고 클릭하면 원본으로 이동
- **핀(고정)** — 메시지에 마우스를 올려 📌 로 고정. 주제/DM 상단 "📌 고정"에서 고정된 메시지 목록을 보고 클릭해 이동(모두에게 공유)
- **고정 신원** — 이름은 최초 1회만 정하면 고정(임의 변경·혼동 방지). 작성·제출·수정이 항상 같은 신원으로 표기되고, 오프라인 구성원의 이름도 명부로 표시됩니다
- **문서함(버전관리)** — 사이드바 📁 에 문서를 올리고 같은 문서에 "새 버전"을 쌓아 이력 관리. `.hwpx`·`.docx`·텍스트는 **버전 간 변경내용을 git처럼 +추가/−삭제로** 표시(구형 `.hwp` 바이너리는 다운로드·이력만). 작은 문서는 전원 복제로 항상 받기 가능
- **메시지 검색** — 사이드바 🔍 로 모든 채널·주제·내 DM에서 텍스트 검색, 결과를 클릭하면 그 대화로 이동
- **대화 내보내기** — 주제/DM 상단 ⬇ 버튼으로 그 대화를 `.txt` 파일로 저장
- **입력 중 표시** — 상대가 입력 중이면 "OOO 님이 입력 중…" 표시(휘발성, 저장 안 함)
- **대화 회수** — 내가 올린 메시지에 마우스를 올리면 🗑 회수 버튼, 누르면 모두에게서 사라짐(본인 것만)
- **주제 대화 리셋** — 주제 화면 상단의 ⟳ 버튼으로 그 주제의 과거 대화를 모두 숨김(전원에게 전파, 주제·이후 대화는 유지)
- **이미지 공유** — 드래그앤드롭 / 붙여넣기(Ctrl·⌘+V, 입력창 포커스 시) / 🖼️ 버튼. 자동 축소 후 전송, 클릭하면 원본 보기
- **파일 공유(zip 등)** — 📎 버튼 또는 드래그앤드롭. **20MB 미만**은 메시지에 담아 즉시 공유, **20MB 이상**은 보낸 사람 PC에 두고 받을 때 직접 가져옴(최대 200MB; 이때 보낸 사람이 접속 중이어야 함)
- 실시간 접속자(동료) 목록 — UDP 발견 기반
- 안 읽은 메시지 배지(채널·주제별), 알림음, 데스크톱 알림
- 대화 기록 로컬 저장(각 PC `data/`), 껐다 켜도 유지
- PC·휴대폰 반응형

## 설치 & 실행 (참여하는 **모든 사람**이 각자)

> 중앙서버가 없으므로 **참여자 전원**이 각자 자기 PC에서 실행합니다.

### 준비물
- **Node.js** (한 번만 설치) — https://nodejs.org 의 LTS 버전
- **(AI 요약을 쓰려면) Ollama** — https://ollama.com 설치 후 터미널에서 `ollama pull gemma3:4b` 한 번 실행. 요약을 안 쓰면 없어도 됩니다(나머지 기능은 모두 정상).

### 실행 (Windows)
1. 이 폴더를 각 PC에 복사합니다.
2. `start.bat` 더블클릭 → (최초 1회 라이브러리 자동 설치) → 브라우저가 자동으로 열립니다.
3. 이름을 입력하고 **입장하기**. 같은 망에서 실행 중인 동료가 자동으로 목록에 나타납니다.

### 명령어로 실행
```bash
npm install   # 최초 1회
npm start     # = node peer.js
```
그 다음 브라우저에서 **콘솔에 표시된 주소**(기본 `http://localhost:34567`)로 접속하세요.
(start.bat / start.command 로 실행하면 브라우저가 자동으로 열립니다.)

## 사용법 (Zulip식 채널 > 주제)

1. 왼쪽에서 **채널**을 고르면, 그 채널의 **주제 목록**이 보입니다.
2. **＋ 새 주제**로 주제를 만들고 첫 메시지를 보냅니다.
3. 주제를 누르면 그 **주제 스레드**에서 대화합니다. (한 채널 안에서 주제별로 대화가 분리됨)
4. 새 메시지가 오면 해당 채널/주제에 안 읽음 배지가 표시됩니다.

## 네트워크 / 방화벽 (중요)

P2P라서 PC끼리 직접 통신합니다. 아래를 확인하세요.

- **Windows 방화벽**: 처음 실행 시 뜨는 "Windows 보안 경고"에서 **개인 네트워크 허용**에 체크.
  (Node.js 가 UDP 발견과 TCP 연결을 받기 위해 필요)
- **같은 서브넷**: 모두 같은 공유기/와이파이(같은 IP 대역)에 있어야 합니다.
- **멀티캐스트 허용**: 대부분의 가정/소규모 사무실 네트워크는 됩니다. 일부 회사망은
  멀티캐스트나 기기 간 통신(AP isolation)을 막아둘 수 있습니다 — 이 경우 망 관리자에게 문의하세요.

### 설정 바꾸기(환경변수)
- `PORT` : 브라우저 UI 포트 (기본 34567 — 사용 중이면 자동으로 다음 포트로 회피하며, 열리는 주소는 콘솔에 표시됨)
- `DISCOVERY_ADDR`, `DISCOVERY_PORT` : 발견용 멀티캐스트 그룹/포트 (기본 `239.255.41.42` / `50505`)
- `LLM_URL`, `LLM_KEY`, `LLM_MODEL`, `LLM_PROVIDER` : **AI 요약**용 LLM 연결. 이 배포본은 **로컬 Ollama `gemma3:4b` 가 기본 내장**(`http://localhost:11434`)되어 있고, 이 환경변수를 설정하면 그 값으로 덮어씁니다.
  - 기본값(각자 자기 PC의 Ollama): `LLM_URL=http://localhost:11434/v1/chat/completions` `LLM_MODEL=gemma3:4b` — 각 PC에 Ollama 설치 + `ollama pull gemma3:4b` 필요
  - 중앙 Ollama 1대 공용: 모든 PC에서 `LLM_URL=http://<그-PC>:11434/v1/chat/completions` (그 PC만 Ollama 설치하면 됨)
  - OpenAI(클라우드): `LLM_URL=https://api.openai.com/v1/chat/completions` `LLM_KEY=sk-...` `LLM_MODEL=gpt-4o-mini`
  - Claude(클라우드): `LLM_PROVIDER=anthropic` `LLM_URL=https://api.anthropic.com/v1/messages` `LLM_KEY=sk-ant-...` `LLM_MODEL=claude-3-5-haiku-latest`
  - ⚠️ 클라우드 LLM을 쓰면 요약 대상 대화가 해당 업체로 전송되고 키가 배포본에 포함됩니다. 기본값인 **로컬 Ollama 는 대화가 외부로 나가지 않고 키도 필요 없습니다**(폐쇄망 권장).

예) 한 PC에서 두 개 띄워 테스트: `set PORT=3001&& set DATA_DIR=data2&& npm start`

## 자주 묻는 문제

**동료가 목록에 안 떠요.**
- 방화벽에서 Node.js 허용을 했는지 (개인 네트워크).
- 같은 와이파이/서브넷인지.
- 회사망이 멀티캐스트/기기간 통신을 막는지 (망 관리자 문의).

**대화 기록을 지우고 싶어요.**
- 주제별로 지우려면: 그 주제를 열고 상단의 **⟳ 주제 리셋** 버튼. 한 명만 눌러도 모든 동료에게서 그 주제의 과거 대화가 숨겨지고, 늦게 접속한 사람도 동기화로 반영됩니다(주제·채널은 유지). 단, 저장 공간을 비우진 않고 "숨김" 처리입니다.
- 저장 공간까지 완전히 비우려면: **참여자 전원이 종료한 상태에서** 각 PC의 `data` 폴더를 삭제하고 다시 실행. (한 명이라도 안 지우고 먼저 접속하면 동기화로 복구됨)
  (`data/identity.json` = 내 노드 신원, `data/store.json` = 채널·메시지)

## 보안 메모
- **P2P 신뢰 모델**: 같은 망의 참여자끼리는 서로 신뢰한다고 가정합니다(노드 간 서명은 없음).
- 메시지 **삭제·수정은 원작성자만** 가능하도록 받는 쪽에서도 검증합니다(위조 차단).
- **DM 및 DM의 리액션/수정/삭제, 대용량 파일**은 **참여 당사자에게만** 전달·동기화됩니다(제3자 차단). 파일은 요청자가 그 대화 참여자인지 확인 후 전송합니다.
- 요약은 **로컬 Ollama 가 기본**이라 배포본에 API 키가 없고, 요약 대화도 외부로 나가지 않습니다. (클라우드 LLM으로 바꾸면 키가 배포본에 포함되니 주의)

## 폴더 구조
```
peer.js            P2P 노드 (UDP 발견 + TCP 메시 + 저장 + 로컬 UI)
public/            브라우저 화면 (HTML/CSS/JS)
data/              내 노드 신원 + 대화 기록 (자동 생성)
start.bat          Windows 실행 도우미
start.command      macOS 실행 도우미
```

## 개발 / 기여 (이어서 개발하실 분)
- 설치: `npm install` → 실행: `npm start` (= `node peer.js`)
- 환경설정: `.env.example` 를 `.env` 로 복사해 값 수정 — **실제 키는 `.env` 에만 두고 절대 커밋하지 마세요**(`.env` 는 `.gitignore` 처리됨)
- 구조·레코드 모델·기능 추가법·편집 함정·테스트·로드맵: **[`DEVELOPMENT.md`](DEVELOPMENT.md)** 참고
- 배포 zip 빌드: `build-dist.ps1` (Windows PowerShell)

## 기술 스택
- Node.js 내장 모듈: `dgram`(UDP 발견), `net`(TCP 메시)
- 로컬 UI 전용: Express + Socket.IO
- 빌드 없는 순수 HTML/CSS/JS 클라이언트
