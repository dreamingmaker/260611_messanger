==================================================
 P2P 사내 메신저 — 맥(macOS) 실행 방법
==================================================

[준비] Node.js 설치 (한 번만)
  https://nodejs.org 에서 LTS 버전을 받아 설치하세요.
  (이미 설치돼 있으면 생략)


■ 방법 1) 터미널로 실행 — 가장 확실함
  1) 받은 zip의 압축을 풉니다.
  2) "터미널(Terminal)" 앱을 엽니다. (Spotlight에서 'terminal' 검색)
  3) 아래처럼 입력하되, 'cd ' 뒤에 압축 푼 폴더를 끌어다 놓고 Enter:
        cd            ← (여기에 폴더를 드래그&드롭)
  4) 실행:
        npm start
     (또는  node peer.js)
  5) 브라우저에서  http://localhost:3000  접속.
     (자동으로 열리면 그대로 사용)


■ 방법 2) 더블클릭으로 실행
  더블클릭이 가능하려면 한 번만 실행 권한을 주면 됩니다.
  1) 터미널에서 폴더로 이동(위 3번과 동일) 후:
        chmod +x start.command
  2) 이후부터는  start.command  를 더블클릭하면 실행됩니다.
     - "확인되지 않은 개발자" 경고가 뜨면:
       start.command 파일을 마우스 우클릭 → 열기 → 열기


■ 사용 & 주의
  - 같은 와이파이(같은 망)의 동료가 자동으로 접속자 목록에 나타납니다.
    (IP 주소 같은 것을 주고받을 필요 없음)
  - 처음 실행 시 "들어오는 네트워크 연결을 허용하시겠습니까?" 가 뜨면
    반드시 "허용"을 눌러주세요.
  - 터미널 창(또는 실행 창)을 닫으면 메신저가 종료됩니다.
  - 회사망이 멀티캐스트/기기간 통신을 막는 경우 연결이 안 될 수 있습니다
    (망 관리자 문의).
